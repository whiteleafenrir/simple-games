# Backend: инструкции для агентов

## Контекст

Применяется к `apps/api/`. Перед изменением engine, repository или persisted state прочитай `GAME_DESIGN.md` и `docs/specs/backend-source-of-truth.md`. Для локального workflow — `docs/specs/local-development.md` и `docs/backend-guide.md`.

## Границы

- Уход, время и жизненный цикл находятся в `src/pets/pet-engine.ts` относительно этой папки. Правила вопросов — `pet-question-rules.ts`, доверие — `pet-trust.ts`, выдача и однократное завершение попытки — `pet-question.service.ts`. Контроллеры занимаются HTTP, service — сценарием, repository — persistence.
- Не дублируй игровой движок во frontend и не меняй баланс без отражения решения в GDD/spec. Виды в MVP должны быть механически нейтральны; не возвращай зависимость сложности от вида через `mode` (исправлено в T3).
- При изменении API сверяй `packages/pet-contract/index.d.ts`, frontend-клиент и Swagger-описание запросов. Интерфейс TypeScript и Swagger не заменяют runtime validation. Доступность действий для UI формирует `pet-snapshot.ts`.
- Для Prisma используй сгенерированные типы. Изменение схемы опиши в spec и укажи способ применения/миграции. Не применяй сброс БД как обход ошибки.
- При изменении чтения/записи проверь параллельные запросы, принадлежность гостю, правило одного активного питомца и целостность истории.

## Проверки

- `npm run build:api` — узкая проверка API; `npm run check` — генерация Client и обе сборки.
- `npm run lint` проверяет код и границы импортов; `npm run format:check` — форматирование текущих изменений.
- `npm run dev:backend` — локальный API с базой; `npm run dev:doctor` — диагностика полного запуска.
- Новые `*.spec.ts` и расширение существующих — только по явному запросу. MVP не требует тестового покрытия. Ручной smoke-check допустим; используй отдельные временные данные и сохраняй пользовательские записи.
- В отчёте различай выполненную проверку и ограничения окружения. Причины и результаты этапов T0–T6: `docs/reports/project-audit-2026-09-07.md`; текущая очередность и открытые решения — в GDD.
