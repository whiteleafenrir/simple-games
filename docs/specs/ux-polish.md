# T6: настройки и полировка интерфейса

**Решение 2026-09-18. Тип:** bug fix/refactor для A15–A16 аудита. Правила игры, баланс и HTTP-контракт не меняются.

- Тема и язык — настройки приложения в этом браузере, без зависимости от фиктивного пользователя. Новый ключ `simple-games:settings`; если его нет, читаются прежние настройки `simple-games:temp-user:settings`. Старый ключ не удаляется, новый используется при последующем сохранении.
- Получение localStorage, чтение, JSON-разбор и запись защищены от ошибок. Повреждённые значения возвращают defaults (`light`, `ru`), допустимые поля сохраняются. При запрете storage или переполнении квоты переключатели продолжают работать в памяти до перезагрузки.
- Меню настроек и профиль не показывают фиктивные имя, логин, роль и внутренние ID. Тексты RU/EN объясняют создание, сохранение, ошибки и отсутствие питомца обычными словами. Язык интерфейса синхронизируется с `html.lang`.
- Сообщения о действиях и ошибках хранят ключ перевода: уже показанное сообщение меняет язык вместе с интерфейсом.
- Пять шкал состояния используют один standalone-компонент на экране ухода, в списке питомцев, подробном профиле и финальном результате. Общий pipe форматирует даты с учётом выбранного языка, включая возвращение с прогулки. Расчёты игровых последствий остаются на сервере.
- Выделение остального UI, lazy routes и state framework не требуются для текущего размера приложения. История остаётся в профиле, её загрузка и пагинация не меняются.

**Проверка:** production-сборка Angular; ручной smoke настроек (обычные, старый ключ, испорченные значения, запрет чтения/записи/доступа, отсутствие браузера); RU/EN и обе темы в браузере, профили активного и завершённого питомцев, узкий экран. Новые `*.spec.ts` не добавляются.

**Текущее состояние 2026-09-19: выполнено.**

- `npm run build` проходит; initial bundle — 408,20 kB, ниже warning budget 500 kB.
- Ручной smoke storage проходит все 18 случаев: defaults, старый и новый ключи, неверный JSON/тип/значения, частично допустимые настройки, отсутствие браузера и ошибки доступа/чтения/записи.
- В браузере проверены RU/EN, обе темы, сохранение после перезагрузки, перенос старого ключа и повреждённый JSON. При запрете доступа к localStorage и ошибке квоты приложение загружается, переключатели работают в памяти, ошибок консоли нет.
- Проверены шкалы и даты в списке, уходе, профилях активного и завершённого питомцев, финальном результате и истории. Сообщение о прогулке переводится при смене языка. На ширине 390 px меню, карточки и история помещаются без горизонтальной прокрутки.
- Браузерная проверка использует локальную production-сборку и временный API с данными в памяти; реальные записи питомцев не менялись. Проверка API и игровой математики не требуется: T6 их не меняет.

**Open questions:** новых продуктовых решений для этого этапа не требуется.
