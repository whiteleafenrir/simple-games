# Focused Specs

Здесь хранятся подробные правила систем; продуктовый объём и очередность остаются в `GAME_DESIGN.md`.

Используй шаблон `docs/ai/feature-spec-template.md`.

Примеры будущих файлов:

- `pet-lifecycle.md`
- `daily-rhythm.md`
- `dragon.md`

Текущие спецификации:

- [Сцена питомца и действия](pet-scene.md) — центральное окно, доступность с сервера, подсказки и мобильная версия.
- [Оболочка приложения](app-experience.md) — главная, альбом историй, навигация и общий визуальный язык.
- [Внешность и реакции](pet-appearance.md) — цвет/рисунок, сохранение, реакции на уход и слой грязи.
- [Мини-игры с питомцем](pet-activities.md) — реализованный первый инкремент: «Слово в облаках», крестики-нолики, серверный зачёт заботы.
- [Вопросы как активность питомца](question-activity.md) — Q1–Q2 реализованы: доверие, вопросы RU/EN, серверные попытки и UI. Контентная часть Q3 расширила банк до 36 заданий; игровые прогоны и баланс остаются Q3, дракон — DLC.
- [Backend source of truth](backend-source-of-truth.md)
- [T4: устойчивость данных и клиента](data-client-resilience.md)
- [T5: миграции, общий контракт и CI](shared-environment.md)
- [T6: настройки и полировка интерфейса](ux-polish.md)
- [Локальная работа с API и базой](local-development.md)
- [Инструменты разработки с ИИ](agent-tooling.md) — карта контекста, lint/format, проектные скиллы и Angular MCP; автотесты отложены.
