# Focused Specs

Здесь хранятся подробные правила систем; продуктовый объём и очередность остаются в `GAME_DESIGN.md`.

Используй шаблон `docs/ai/feature-spec-template.md`.

Примеры будущих файлов:

- `pet-lifecycle.md`
- `daily-rhythm.md`
- `dragon.md`

Текущие спецификации (статусы сверены 2026-09-28; очередность — в [roadmap](../../GAME_DESIGN.md#14-roadmap)):

- [Сцена питомца и действия](pet-scene.md) — S1–S2 реализованы: сцена, доступность с сервера, мобильные действия, анимации и реакции; S3 с окружением и возрастными образами остаётся открытым. Поглаживание — только превью.
- [Оболочка приложения](app-experience.md) — реализованы главная, альбом историй, навигация и общий визуальный язык.
- [Внешность и реакции](pet-appearance.md) — реализованы цвет/рисунок при создании и редактировании, сохранение, реакции на уход и слой грязи.
- [3D-прототип кота](pet-3d-prototype.md) — процедурная модель без Blender, совместная поддержка SVG/3D, ракурсы и поза «Крадётся»; финальная модель и возрастные формы остаются следующими итерациями.
- [Мини-игры с питомцем](pet-activities.md) — «Слово в облаках», крестики-нолики и шахматные задачи с общим серверным зачётом заботы.
- [Шахматные задачи](chess-puzzles.md) — отдельный модуль правил, восемь задач, самостоятельный экран и запуск через «Поиграть»; полноценный соперник остаётся следующим шагом.
- [Вопросы как активность питомца](question-activity.md) — Q1–Q2 реализованы: доверие, вопросы RU/EN, серверные попытки и UI. Контентная часть Q3 расширила банк до 36 заданий; игровые прогоны и баланс остаются Q3, дракон — DLC.
- [Backend source of truth](backend-source-of-truth.md) — основная вертикаль и T1–T3 реализованы.
- [T4: устойчивость данных и клиента](data-client-resilience.md) — реализовано.
- [T5: миграции, общий контракт и CI](shared-environment.md) — реализовано; первое общее размещение остаётся отдельной работой.
- [T6: настройки и полировка интерфейса](ux-polish.md) — реализовано.
- [Локальная работа с API и базой](local-development.md)
- [Инструменты разработки с ИИ](agent-tooling.md) — карта контекста, lint/format, проектные скиллы и Angular MCP; автотесты отложены.
