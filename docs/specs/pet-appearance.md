# Внешность и временные реакции питомца

**Решение, 2026-09-23. Тип задачи: implementation.** Существующий SVG подходит: силуэт вида, палитра, рисунок, загрязнение и мимика остаются независимыми слоями. Растровые скины для каждой комбинации не нужны.

- После подтверждённой игры — радость на 5.2 секунды (два полных цикла), после кормления/лакомства — довольная реакция на 4 секунды, уборки — пузырьки на 4 секунды, пробуждения — спокойная реакция на 3 секунды. После ответа на вопрос — радость, после отказа — задумчивость. Затем возвращается актуальное серверное настроение; базовая радость в комнате имеет спокойное дыхание и улыбку. Реакция не меняет статы и не воспроизводится заново при polling или перезагрузке. Следующее успешное действие заменяет её; сон, прогулка и конец сессии имеют приоритет.
- Внешность: шесть палитр (`natural`, `honey`, `ash`, `rose`, `lavender`, `mint`) и три рисунка (`plain`, `spots`, `stripes`). Это бесплатная косметика без влияния на баланс. Выбор при создании и редактирование активного питомца с предпросмотром и явным сохранением. Альбом и главная используют сохранённый облик. Завершённый питомец сохраняет последний облик.
- Грязь выводится по серверной чистоте: плавно появляется ниже 70, усиливается до 25 и ниже. Она лежит поверх окраса, под мимикой и двигается вместе с головой/телом при любой эмоции и во сне. Уборка уменьшает загрязнение согласно фактическому новому значению чистоты, а не безусловно очищает картинку.
- Галерея позволяет менять палитру, рисунок и чистоту для всех видов и состояний, запускать временную реакцию с возвратом к спокойной позе. Галерея не обращается к API.

## Создание питомца (уточнение 2026-09-26)

**Решение. Тип задачи: implementation / UX.** Настройка внешности — отдельный видимый шаг сразу после выбора вида: крупное живое превью, шесть цветов и три рисунка с образцами. Имя и выбранные цвет/рисунок отображаются рядом с превью и в итоговом выборе. При смене вида цвет и рисунок сохраняются в черновике.

«Случайный облик» выбирает другое сочетание из существующей палитры; «Сбросить облик» возвращает `natural`/`plain`, не меняя имя, вид и длительность. Выбор остаётся черновиком до кнопки создания, затем сохраняется в существующих полях питомца на backend. Во время отправки параметры заблокированы; при ошибке черновик сохраняется. Подсказка объясняет сохранение и возможность последующего редактирования активного питомца. Новых полей и миграций этот шаг не требует.

**Приёмка:** ручной выбор, случайный облик и сброс; смена вида без потери выбора; создание и повторное чтение после перезагрузки; совпадение вида в комнате, на главной и в альбоме; RU/EN и мобильная ширина.

**Проверено 2026-09-26:** production frontend и API собраны, Prisma Client сгенерирован; сохранённые миграции уже применены. В браузере проверены ручной выбор, случайное сочетание, сброс с сохранением имени и смена вида без потери внешности; RU/EN, светлая/тёмная темы, ширина 360 и 1280 px без горизонтального скролла. Временная собачка с `lavender`/`stripes` создана через форму: поля подтверждены в PostgreSQL, после перезагрузки цвет и полоски совпали в комнате, на главной и в альбоме. Временный питомец удалён, ошибок JavaScript не обнаружено. Постоянные тесты не добавлялись.

## Хранение и API

`Pet.coatColor` и `Pet.coatPattern` — строки с defaults `natural`/`plain` и SQL CHECK. Общий контракт передаёт `appearance: { color, pattern }`. Старые записи получают defaults через аддитивную миграцию `20260923000000_pet_appearance`; применить `npm run db:deploy`, затем `npm run check`, перезапустить API. Сброс базы не нужен.

Создание принимает необязательный `appearance`; `PATCH .../pets/:petId/appearance` принимает оба поля и возвращает актуальный snapshot. Runtime validation отвергает неизвестные ключи/значения. Изменение выполняется в существующей транзакции с блокировкой гостя: только свой активный питомец, без расхода энергии, cooldown и событий ухода; время по-прежнему разрешается сервером. Гонки с уходом/чтением не теряют внешность или статы. localStorage не используется.

## Приёмка

Обе сборки; ручная проверка сохранения/чтения, старых defaults, неверных значений, чужого/завершённого питомца и параллельного ухода. В браузере: реакция → обычное состояние, отказ действия без реакции, сон; цвет/рисунок/грязь во всех настроениях, мобильная ширина, RU/EN, reduced motion. Постоянные тесты не добавляются.

**Допущение:** выбранных палитр и двух декоративных рисунков достаточно для первого набора. Произвольные цвета, аксессуары и другие внешние эффекты можно добавить теми же слоями.
