# Ежедневные факты о животных

**Основа:** решение владельца от 2026-10-02, GDD §14.2.2. **Тип:** implementation. **Статус:** первый инкремент реализован и проверен, 2026-10-04.

## Объём и допущения первого инкремента

- В комнате активного питомца — компактная карточка «Факт дня» после самочувствия, перед настройкой внешности. Энергия игрока скрыта по решению от 2026-10-10. Сон и прогулка не скрывают карточку. В создании, альбоме и завершённой сессии её нет.
- По восемь коротких фактов для кошки, собаки, попугая и динозавра, с одинаковым смыслом RU/EN и ссылкой на источник у каждого. Динозавр получает сведения о реальных вымерших животных, с названием конкретного рода. Дракон не получает фактов.
- **Допущение:** единые сутки UTC, смена в 00:00 UTC. Backend выбирает факт по виду и номеру календарного дня, циклически в стабильном порядке. Все питомцы одного вида получают одинаковый факт в один день. Перезагрузка, новый питомец, язык, часовой пояс устройства и действия не меняют выбор внутри суток.
- Восемь фактов покрывают даже семь полных суток сессии, которые могут затронуть восемь календарных дат. Пропущенные дни не накапливаются. После восьми дней цикл повторяется; это небольшой стартовый банк, а не бесконечная лента. Изменение порядка/состава каталога при следующем выпуске может изменить текущий факт.
- Обновление приходит с существующим snapshot: polling раз в 30 секунд, возвратом на вкладку или действием. Отдельного таймера/запроса нет. Без сети сохраняется последний полученный факт с его датой и существующей ошибкой синхронизации; клиент не выдаёт новый факт по своим часам.
- Дата карточки форматируется на языке UI в UTC. Ссылка открывает источник в новой вкладке; внешние страницы могут быть на английском.

## Контракт и данные

`PetSnapshot.dailyFact` — вычисляемый `PetDailyFact | null`: стабильный `id`, календарная `day` (`YYYY-MM-DD` в UTC), `sourceName`, `sourceUrl`. Для завершённого питомца и дракона — `null`. Каталог ID/источников и выбор находятся в API; тексты и подписи UI — в `src/app/i18n/translations.ts`. Общий контракт ограничивает ID типом, чтобы обе локализации проверялись сборкой.

Выбор не пишет в БД и не меняет уход, историю, доверие, ресурсы или финал. Миграция, новый endpoint, localStorage и внешние запросы во время игры не нужны. На UI факт приходит во всех существующих ответах со snapshot, включая создание, действия, вопросы и изменение внешности.

## Проверка

- Все 32 ID уникальны, соответствуют виду, имеют две непустые локализации и HTTPS-источник.
- Для каждой длительности 1/3/7 дней: стабильность в течение суток, смена ровно на границе UTC, восемь последовательных календарных дат без повторов, возврат после пропуска, границы месяца/года и високосного февраля.
- Один момент с разными часовыми смещениями даёт одинаковый факт. Сон, прогулка, взросление, внешность и уход не меняют выбор. Оба финала убирают карточку; новый питомец получает факт своего вида.
- Разовый прогон backend snapshot и браузерная проверка RU/EN, светлой/тёмной темы, desktop/320 px, перезагрузки и сетевой ошибки. Lint, форматирование, обе сборки. Постоянные тесты не добавляются.

## Результат проверки, 2026-10-04

- База изменения — `2263b08` плюс текущий diff. Проверены 32 уникальных ID, 64 локализованных текста (каждый короче 200 символов), соответствие вида и HTTPS-ссылки. Разовый прогон подтвердил 288 сравнений внутри суток, восемь дат без повторов, циклический возврат, переход месяца/года и високосного февраля, равные моменты с разными смещениями UTC.
- Настоящие `PocketPetService`, `PetQuestionService` и Prisma repository на PostgreSQL: 12 временных сессий (четыре вида × 1/3/7 дней). Факт присутствует в создании, списке, чтении, ответах ухода, выдаче/ответе вопроса и изменении внешности. Сохраняется при сне/прогулке, меняется после полуночи; пропуск дней, завершение и следующий питомец отработали. Отдельно snapshot проверен для обоих финальных статусов и дракона, без мутации входных данных и дополнительных запросов ради факта.
- Временные гости удалены в `finally`. Контрольные суммы всех девяти исходных таблиц до/после совпали. Миграции и schema не менялись.
- Production frontend проверен в браузере на сохранённых ответах этих временных сессий через изолированный локальный fixture-сервер. RU/EN меняются без смены факта, светлая/тёмная темы и 320 px читаемы, горизонтального переполнения нет. Перезагрузка сохраняет факт. Ответ `503` оставляет прежний текст с датой и показывает общую ошибку; повтор после восстановления получает факт следующего дня. Сон и прогулка не скрывают карточку, в завершённой сессии её нет. Это проверка UI с подставными ответами; отдельный HTTP-прогон Nest и полный игровой цикл не проводились.
- `npm run quality` прошёл: lint, форматирование, Prisma Client и обе сборки. Начальный bundle — 455.30 kB при бюджете 500 kB. Разовые материалы сохранены только в игнорируемой `.local/daily-facts-check/`; постоянные тесты/runner не добавлены. Полная приёмка гостевой версии, Q3 и remote CI остаются за рамками этого шага.
