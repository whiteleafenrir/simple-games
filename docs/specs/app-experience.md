# Интерфейс Pocket Pet

**Решение, 2026-09-21:** приложение строится вокруг заботы о питомце. Тип задачи — продуктовый дизайн и реализация интерфейса; правила и баланс не меняются.

- Бренд — Pocket Pet. Навигация: «Домой», «Питомец», «Альбом», настройки языка и темы.
- Главная — место возвращения. При активном питомце показывает имя, состояние и переход к уходу. Без питомца знакомит с четырьмя видами, предлагает выбрать друга и объясняет ритм заботы. Завершённые истории доступны в альбоме.
- Загрузка и ошибка не выдаются за отсутствие питомцев. При ошибке доступен повтор.
- Мини-игры убраны из навигации и промотекстов. Их код, переводы и прямые маршруты сохранены.
- Визуальная система: тёплая бумажная палитра, лесной зелёный, мягкие карточки, спокойная типографика; полноценная тёмная тема.
- Общий SVG-компонент животных на главной, при выборе, в сцене, альбоме и профиле. Различимые силуэты, выражения настроения и сна. Анимация только на сцене с учётом reduced motion.
- Выбор на главной передаётся через query parameter; создание происходит только после ввода имени и явного действия. Дракон остаётся заблокированным.
- Альбом показывает короткие карточки историй; подробные статы, даты и история остаются в профиле. Активный питомец имеет прямую кнопку возврата к уходу.

## Приёмка

RU/EN, светлая/тёмная темы, ширина 360 px и desktop; главная с питомцем и без, выбор, сцена, альбом, профиль, ошибки и загрузка. Старые ссылки работают. Сборка frontend проходит; тестовое покрытие отдельной задачей.

**Open questions:** нет; направление выбрано в рамках запроса владельца на самостоятельную переработку интерфейса.

## Проверка реализации, 2026-09-21

- `npm run check` — Prisma Client, API и production frontend собраны успешно. После финальной корректировки CSS повторно прошёл `npm run build`.
- Headless Edge: главная на 360/768/1440 px, границы карточек, создание по выбранному на главной виду и переход в сессию с прокруткой наверх, пустой альбом, профиль и история ухода.
- На отдельных тестовых гостях проверены сон и отображение на главной, мобильная карточка действия и кормление, настройки RU/EN и обе темы, прямой маршрут крестиков-ноликов.
- Временные ответы API в браузере: архивный питомец, ссылка на воспоминания, ожидание загрузки, ошибка и успешный повтор. Данные реальных гостей не заменялись.
- Дракон остаётся недоступным, неизвестный/заблокированный query parameter не выбирает его. Ошибок JavaScript нет.
- Локальные скриншоты и сценарии проверки лежат в игнорируемой `.local/ui-review/`; постоянные тесты не добавлялись.
