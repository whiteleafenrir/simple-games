# Проверка гостевого цикла, 2026-10-05

**Тип:** проверка и bug fix. Выполнен самостоятельный технический инкремент шага 2 из [roadmap §14.1.1](../../GAME_DESIGN.md#1411-ближайший-фокус-завершение-гостевой-версии). Исходная версия — `24a2139`, затем локальное исправление комнаты. Баланс и контракт не менялись. Это не закрытие всего шага 2, Q3 или приёмки выпуска.

## Исправленная ошибка

**Воспроизведение:** при активном питомце открыть пункт навигации «Питомец», оставив адрес `/games/pocket-pet`, и дождаться завершения сессии сервером. После polling `activePet` исчезал, а комната заменялась созданием нового питомца без прощания. При прямом адресе с ID итог отображался корректно.

**Исправление:** общий адрес активной комнаты заменяется адресом конкретного питомца через `replaceUrl`. Завершение оставляет комнату на том же питомце. Форма создания по общему адресу без активного питомца сохраняется. Открытая архивная история не должна переключаться на активного друга.

## Выполненные проверки

Локальные Angular 22.1.5, Node 26.1.0, NestJS и PostgreSQL 17.10. Пять существующих миграций применены; проверка не добавляла миграций и не меняла схему. Для ускоренной проверки финала изменялись только даты и статы временных питомцев; обычные действия, ограничения, завершение и создание следующего питомца выполнялись через реальные API/UI.

### API и PostgreSQL

Для `short`, `standard`, `long` на отдельных новых гостях:

- Длительности ровно 1/3/7 дней; второе создание при активном питомце возвращает `409`.
- Два параллельных `play` дают один успех и один отказ `cooldown`.
- Выключение света запрещает кормление и выдачу вопроса; включение возвращает уход. Прогулка запрещает кормление.
- Повтор открытия вопроса, включая запрос другого языка, возвращает ту же попытку. Повтор отправленного отказа возвращает тот же результат, доверие остаётся 50, в истории один разговор.
- По шесть записей заботы: игра, два переключения света, кормление, уборка, прогулка. Отказы не добавляют событий.
- Проверены `grown` и `left`. После финала уход и новый вопрос дают `inactive`, ежедневный факт отсутствует. Повторное чтение не меняет farewell, история до и после финала совпадает.
- Новый питомец создаётся, остаётся ровно один активный, итог прежнего питомца сохраняется.

Успешный HTTP-прогон использовал гостей `d44e8c87-25ea-4c7f-b50f-17097deb5d8a`, `600ac88f-408b-493f-9c2e-f569e4500f7f`, `e50ac3a3-13a7-465c-8679-c4b29efc84e8`. После проверки они и связанные данные удалены. Предварительный запуск также очистил своего временного гостя в `finally`.

### Браузер

- Создание → комната → сохранение при перезагрузке → альбом → профиль с историей → создание следующего питомца.
- Бесплатное открытие/закрытие выбора игр, Escape и возврат фокуса. Двойное нажатие первой игры, новая партия и переходы между словами, крестиками-ноликами и шахматами оставили одну запись `play` и одно списание 15 энергии.
- Серверное обновление сна остановило крестики-нолики, прогулка остановила шахматы. После включения света открытая сессия продолжала разрешать игры без повторного списания.
- При остановленном локальном API выбор первой игры показал ошибку внутри окна; игра не открылась, число событий и энергия не изменились. После запуска API и успешного polling повтор в том же окне запустил игру. Это проверка недоступности backend через dev proxy, а не потери ответа после commit.
- Финал `grown` виден в альбоме и профиле; история содержит реальные действия. На втором питомце проверены `left` и остановка игры при финале после исправления маршрута. Перезагрузка сохраняет прощание.
- На третьем питомце проверены создание после финала, перевод общего адреса на адрес активного питомца и возврат браузерной кнопкой «Назад» сразу на главную. Прямая ссылка на завершённого питомца сохраняет прежнюю историю при наличии нового активного друга.

В браузере использованы только созданные для проверки питомцы `f364bb7a-e677-4988-8293-49ce6b020342`, `48be03b5-8bfa-4e2b-88f8-356441394821` и `9c7590f8-7f5c-4473-8b82-69c261260344`. Браузер восстановил существующую гостевую cookie с архивной историей. **Очистка завершена 2026-10-08:** удалены только три временных питомца с точными ID, существующий гость сохранён. До и после очистки совпали контрольные суммы остальных девяти питомцев, их статов, энергии, cooldown, истории, вопросов и финалов.

## Расчётные наблюдения о балансе

Это ручной прогон существующих чистых функций с явным временем, без постоянного runner и без новой системы подготовки состояний. Модель: создание в 08:00, возвращения в 08:00/15:00/22:00, при каждом возвращении кормление → уборка → игра; в 22:00 выключение света, в 08:00 включение. Вариант пропуска исключает весь второй день. Прогулки, джанкфуд и вопросы в эту модель не включены. Ритм выбран только для сравнения, он не является решением владельца.

| Режим                               | 1 день        | 3 дня         | 7 дней        |
| ----------------------------------- | ------------- | ------------- | ------------- |
| Без возвращений, свет включён       | `left`, 37.3  | `left`, 0     | `left`, 0     |
| Три возвращения в сутки             | `grown`, 75.6 | `grown`, 64.0 | `grown`, 53.2 |
| Тот же ритм с пропуском второго дня | Не применимо  | `grown`, 50.8 | `grown`, 53.2 |

**Наблюдение:** к концу семидневного прогона с тремя возвращениями сытость и здоровье равны 0, но чистота 72, радость 94 и энергия питомца 100 дают среднее 53.2 и `grown`. Энергия игрока после визита не опускалась ниже 80. Это соответствует нынешним формулам; автоматически менять числа или финальную оценку по результату одного условного ритма нельзя. Наблюдение относится к уже открытым решениям о целевом ритме и смысле финала.

Также проверены возрастные границы 20%/70% для всех длительностей, восьмичасовой сон, окончание прогулки ровно через 30 минут, восстановление недостающей единицы энергии игрока за пять минут и одинаковый farewell при чтении на границе/через трое суток после неё.

## Ограничения и оставшаяся работа

- Реального ожидания 1/3/7 дней и пользовательской оценки сложности RU/EN не было; Q3 остаётся открытым.
- Потерянный ответ после сохранения команды, настоящий offline, таймаут, все исходы вопросов, полная матрица игровых побед/проигрышей, нагрузка и мобильная производительность 3D не проверялись этим прогоном.
