# Implementation Plans

Здесь хранятся планы реализации крупных задач с отметками выполненных этапов.

Используй шаблон `docs/ai/implementation-plan-template.md`.

План нужен, когда работа затрагивает несколько модулей, требует миграций, backend-контрактов, новых игровых правил или нескольких этапов проверки.

Очередность определяет [roadmap GDD](../../GAME_DESIGN.md#14-roadmap). На 2026-10-04 `T0–T6`, `S1–S2` и `Q1–Q2` реализованы; контентная часть `Q3` готова, оценка игрового ритма и баланса остаётся открытой. До завершения гостевого выпуска добавлены шахматы с каталогом Lichess, 3D-прототип кота, исправления UX и ежедневные факты; фактическое отклонение от очередности зафиксировано в GDD. Ближайший предлагаемый крупный шаг — [завершение гостевой версии](../../GAME_DESIGN.md#1411-ближайший-фокус-завершение-гостевой-версии). [Аудит](../reports/project-audit-2026-09-07.md) хранит причины и исторические доказательства технических задач MVP. Планы описывают конкретные инкременты и не создают отдельную дорожную карту.

Незавершённый этап:

- [Гостевой цикл на 21 день](guest-release-cycle.md) — согласованные ритм и длительность; первый инкремент сохраняет скрытую энергию игрока с нулевым расходом. Далее — длительность/возраст, баланс и содержание. Сон по усталости добавлен отдельным этапом roadmap.
- [Q3: расширение банка вопросов](q3-question-content.md) — контентный инкремент выполнен: 36 заданий RU/EN; игровые прогоны и окончательный баланс всего Q3 остаются открытыми.

Выполненные планы:

- [Ежедневные факты](daily-animal-facts.md) — 32 факта RU/EN с источниками, ежедневный выбор сервером и карточка в комнате; инкремент GDD §14.2.2.
- [Шахматный модуль и задачи](chess-puzzles.md) — независимые правила, отдельный экран и подключение к «Поиграть»; первоначальные восемь позиций заменены каталогом Lichess в БД с рейтингом и многоходовыми решениями.

- [S1: сцена питомца](s1-pet-scene.md) — выполнено; первый вариант desktop/mobile. Последующие S2, внешность и новая оболочка описаны в [спецификациях](../specs/README.md); S3 остаётся расширением.
- [Q1: доверие и основа правил вопросов](q1-question-foundation.md) — выполнено.
- [Q2: вопросы обычных питомцев](q2-question-activity.md) — выполнено; серверные попытки, история и UI.

Первый инкремент мини-игр реализован по [focused spec](../specs/pet-activities.md); отдельного плана в этой папке нет. Новый план создаётся перед следующим существенным изменением, без повторного планирования готовых систем.

Исторические планы:

- [Backend MVP инкремент](backend-mvp-implementation.md) — реализован; последующие этапы `T1–T5` также завершены.
