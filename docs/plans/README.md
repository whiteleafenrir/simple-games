# Implementation Plans

Здесь будут жить планы реализации для крупных задач.

Используй шаблон `docs/ai/implementation-plan-template.md`.

План нужен, когда работа затрагивает несколько модулей, требует миграций, backend-контрактов, новых игровых правил или нескольких этапов проверки.

Очередность определяет [roadmap GDD](../../GAME_DESIGN.md#14-roadmap): [технический трек MVP](../../GAME_DESIGN.md#144-техническая-готовность-и-очередность) содержит этапы `T1`–`T6`, [активность «Вопросы»](../../GAME_DESIGN.md#1421-активность-вопросы) — запланированные `Q1`–`Q3` рабочей версии. [Аудит](../reports/project-audit-2026-09-07.md) хранит причины и доказательства технических задач MVP. Планы в этой папке описывают реализацию конкретного этапа и содержат его номер; они не создают отдельную дорожную карту. План вопросов составляется перед началом реализации, правила уже находятся в [спецификации](../specs/question-activity.md).

Текущие планы:

- [Q1: доверие и основа правил вопросов](q1-question-foundation.md) — выполнено; содержит фактические результаты проверки, далее Q2.

Исторические планы:

- [Backend MVP инкремент](backend-mvp-implementation.md) — реализован; дальнейшие backend-задачи распределены по `T1–T5`.
