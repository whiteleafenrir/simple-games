# Ежедневные факты: первый инкремент

**Тип:** implementation. **Статус:** выполнено, 2026-10-04. Основа — [спецификация](../specs/daily-animal-facts.md) и GDD §14.2.2.

1. Проверить источники и подготовить 32 коротких факта RU/EN для четырёх доступных видов.
2. Добавить общий тип и серверный выбор по суткам UTC в существующий snapshot, без изменения persisted state.
3. Показать компактную карточку в комнате, сохранив приоритет ухода на телефоне.
4. Проверить ротацию/границы разовым прогоном, API snapshot, отображение и локализации в браузере; выполнить lint, форматирование и обе сборки.
5. Записать результат и ограничения, обновить статусы GDD и индексов с учётом уже добавленных шахмат и 3D-прототипа.

Все пять шагов завершены. [Результаты проверки и ограничения](../specs/daily-animal-facts.md#результат-проверки-2026-10-04): 32 факта, 288 сравнений внутри суток, 12 временных сессий PostgreSQL с сохранностью исходных данных, браузер RU/EN и 320 px, `npm run quality`. Правила заботы и база данных не менялись; открытых блокирующих вопросов нет.
