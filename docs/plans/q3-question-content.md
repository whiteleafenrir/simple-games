# Q3: расширение банка вопросов

**Статус:** контентный шаг выполнен, 2026-09-20; весь этап Q3 ещё не завершён. Тип: implementation. Основа — [спецификация](../specs/question-activity.md#контентный-шаг-q3-2026-09-20).

1. Расширить серверный каталог с 12 до 36 заданий RU/EN: по 12 на каждый возраст, с однозначным ответом и коротким объяснением.
2. Сохранить ID, версии и содержание исходных заданий, API, сохранённые попытки и стартовые эффекты Q1. Миграции и изменения UI не нужны: обе локализации приходят в существующем контракте.
3. Проверить структуру и смысл банка, выдачу всех заданий на обоих языках, отсутствие повторов до исчерпания категории, смену возраста/языка и сохранение результатов. Использовать временные in-memory данные, без нового тестового покрытия.
4. Прогнать сценарии выдачи для сессий 1/3/7 дней с тремя и четырьмя разговорами в сутки и с максимальной частотой раз в 30 минут; зафиксировать границы банка. Выполнить `npm run build:api`, затем `npm run check`.

## Open questions

Достаточность банка для реального ритма игрока и настройка баланса остаются в Q3. Три разговора в сутки — рабочее допущение этого шага, не обязательный ритуал и не ограничение.

## Результаты

- Каталог: 36 заданий (72 локализованных варианта), по 12 на возраст. Добавлены 24 задания о счёте, природе, наблюдениях, порядке, условиях и выборе решения. Проверены формулировки, ответы и соответствие переводов; правильная позиция при объявлении задания ограничена типом `1 | 2 | 3 | 4`.
- Сравнение с исходным каталогом подтвердило неизменность всех 12 прежних определений. Структурная проверка подтвердила уникальность ID и формулировок, четыре различных варианта, правильный ID и полное содержание обеих локализаций.
- На временном in-memory repository выполнены 78 попыток: все 36 заданий выданы на RU/EN, по 12 уникальных вопросов на возраст и следующий повтор после исчерпания. Проверены три исхода и фактические дельты, отсутствие правильного ответа до завершения, порядок вариантов в обоих языках, повтор без двойного эффекта, cooldown на границе и история. Сохранённые снимки прошли mapper, используемый PostgreSQL; сама БД в этом шаге не менялась и повторно не проверялась.
- Обе возрастные границы проверены отдельно: открытая попытка сохраняет вопрос и порядок при взрослении/смене языка, а следующая получает новый возраст.
- `npm run build:api` и `npm run check` прошли; `git diff --check` не выявил ошибок пробелов. Новые `*.spec.ts` не добавлялись, тестовый набор не запускался. UI не менялся; отдельная браузерная проверка в этом шаге не проводилась.

### Частота и границы банка

Девять прогонов серверной выдачи на сессиях 1/3/7 дней. Разговоры размещены равномерно, первый — через половину интервала после создания, языки чередуются. Считается каждая выдача уже встречавшегося ID. Паузы сна и прогулки в этой модели не включены; это оценка запаса контента, а не приёмка игрового баланса.

Во всех прогонах категория сначала исчерпывалась без повторов, непосредственно предыдущий вопрос не выдавался повторно. Для принятой модели трёх разговоров в сутки банка достаточно. При четырёх разговорах за неделю повторяется подростковая категория; для интенсивного ритма раз в 30 минут текущий банк рассчитан на повторы. Размер банка и cooldown следует оценить на реальных игровых сессиях перед завершением всего Q3.
