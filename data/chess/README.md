# Стартовый каталог шахматных задач

`lichess-puzzles.csv` — 1500 задач из [Lichess Open Database](https://database.lichess.org/#puzzles), полученных 2026-10-03. Исходный архив: `https://database.lichess.org/lichess_db_puzzle.csv.zst` (HTTP Last-Modified: 2026-10-02). Данные распространяются под [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/); их можно использовать, изменять и распространять. Это лицензия данных, не серверного кода Lichess.

Срез: первые 500 подходящих уникальных задач каждого уровня (<1200, 1200–1799, ≥1800) из потока, затем сортировка по рейтингу/id. Условия: popularity ≥80, NbPlays ≥100, RatingDeviation ≤100, корректный FEN и полностью легальная UCI-линия. Рейтинги — снимок источника на дату получения. Это небольшой стартовый каталог, не репрезентативная случайная выборка всей базы.

FEN сохранён **до** первого хода соперника. API применяет первый ход `Moves` и передаёт оставшуюся линию как решение. Темы и opening tags сохранены в оригинальном виде.

Локальная загрузка: `npm run chess:seed` (также входит в `npm run dev`). Повтор добавляет только отсутствующие id и не откатывает обновлённые рейтинги.

Для нового среза, без записи в БД:

```powershell
node scripts/chess-download.mjs --output .local/lichess-puzzles.csv --per-level 500
```

Скачивание потоковое и прекращается после заполнения трёх уровней; полный архив не сохраняется. Обновление БД после проверки файла:

```powershell
node scripts/chess-import.mjs --file .local/lichess-puzzles.csv --limit 1500
```

Импорт также принимает локальный `.csv.zst`, обрабатывает порциями по 100 и выполняет upsert по id. По умолчанию лимит 10000 валидных строк; укажите явный больший лимит для большого каталога. Импорт не применяет фильтры стартового среза, не удаляет остальные задачи; некорректные строки пропускаются с итоговым счётчиком. После ошибки завершённые порции остаются в БД, повтор безопасен. Для `.zst` используется `fzstd`, поскольку встроенный декодер Node 26.1 преждевременно заканчивает чтение архива Lichess на служебном frame.
