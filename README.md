# Simple Games

Браузерные игры на Angular 22 standalone components. Основное направление — **Pocket Pet**: забота о фэнтези-питомце в ограниченной жизненной сессии. Дополнительно есть крестики-нолики.

Стек: Angular + NestJS API + PostgreSQL 17 + Prisma 7. Состояние питомцев хранится на backend, гостевая сессия восстанавливается через HttpOnly-cookie.

## Запуск

```powershell
npm install
npm run dev
```

Команда использует PostgreSQL из `.env` (или поднимает стандартную Docker-базу), применяет схему и запускает игру, API с перезапуском и Prisma Studio. На текущем компьютере уже есть PostgreSQL на порту `5435`; Docker не нужен. На новой машине нужен существующий PostgreSQL или запущенный Docker Desktop; `.env.example` содержит Docker-подключение.

Открыть всё во втором терминале: `npm run dev:open`. Остановить приложения: **Ctrl+C**, данные сохраняются.

- [Игра](http://localhost:4200/games/pocket-pet)
- [Backend: Swagger](http://localhost:3000/api/docs)
- [База: Prisma Studio](http://localhost:5555)

Диагностика: `npm run dev:doctor`. Только база и таблицы: `npm run db:studio`. Проверка сборок: `npm run check`. В PowerShell при блокировке `npm.ps1` используйте `npm.cmd`.

**Подробная инструкция:** [как запускать, открывать и смотреть backend и базу](docs/backend-guide.md).

## Roadmap

1. **MVP — текущий этап:** гостевая сессия, один активный питомец, уход, сон, прогулки, энергия, взросление и сохранённый итог. Основная вертикаль реализована; ближайшие технические этапы — безопасная граница API, целостность записи и корректный расчёт времени (`T1–T3`).
2. **Рабочая версия:** аккаунты и синхронизация, различия видов, восприятие игрока, вопросы и мини-игры.
3. **DLC:** дракон, расширенный жизненный цикл и AI-диалоги.

Подробный объём, техническая очередность и non-goals находятся в [roadmap GDD](GAME_DESIGN.md#14-roadmap). Причины и доказательства задач — в [аудите](docs/reports/project-audit-2026-09-07.md). Тестовое покрытие отложено до стабилизации MVP и добавляется отдельной задачей.
