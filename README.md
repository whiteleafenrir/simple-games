# Simple Games

Небольшая Angular-песочница для простых браузерных игр.

Стек: Angular 21 standalone components + SVG.

## Разработка

Для AI-assisted разработки в репозитории есть [AGENTS.md](AGENTS.md) и легкий процесс в [docs/ai](docs/ai). Подробные продуктовые решения живут в [GAME_DESIGN.md](GAME_DESIGN.md), а README остается короткой дорожной картой и инструкцией запуска.

## Roadmap

Подробный дизайн и критерии готовности: [GAME_DESIGN.md](GAME_DESIGN.md).

### MVP

Минимально завершенная версия Pocket Pet с созданием питомца, базовым циклом заботы, профилем, backend и базой данных.

1. Pocket Pet v1: питомец появляется сразу ребенком, взрослеет по этапам `child -> teen -> adult` и всегда уходит: либо потому что вырос и начинает собственную жизнь, либо потому что ему не хватало заботы. Смерти и ожидания вылупления нет.
2. Backend Foundation: отдельный NestJS API, PostgreSQL и Prisma. Backend становится источником истины для состояния питомца, времени, действий, сна, прогулок, cooldown и ресурсов игрока.
3. Guest Mode: в MVP нет регистрации; backend хранит состояние по анонимному guest id, а localStorage используется только для guest id и возможного кэша.
4. Pet Creation: игрок создает только питомца: вид, имя и длительность сессии. Можно иметь только одного активного питомца.
5. Care Loop: базовая еда, джанкфуд как быстрый бонус с вредом здоровью, уборка, игра одной кнопкой, прогулка с временной недоступностью питомца и свет как часть режима сна.
6. Daily Rhythm Foundation: вечером игрок выключает свет и укладывает питомца спать, утром включает свет и делает базовый уход после сна.
7. Player Energy & Activity Budget: у игрока есть мягкий ресурс сил для активностей; часть действий бесплатна, часть тратит ресурс, а ресурс восстанавливается со временем.
8. Farewell & Results: при уходе сохраняются причина, дата, итоговая фраза, финальный балл заботы, финальные статы и подробная история действий для профиля.

### Рабочий проект

Версия, где игра ощущается цельной: аккаунты, синхронизация, стабильный профиль, полноценный цикл заботы, мини-игры и расширенный контент.

1. Account & Sync: авторизация через Google-почту, перенос гостевого состояния в аккаунт и синхронизация между устройствами.
2. Species Traits: виды питомцев получают реальные отличия в реакциях на действия, расписание, восстановление и ухудшение статов.
3. Pet Perception v1: питомец формирует мнение об игроке по истории заботы: строгость, балование, регулярность заботы и невнимательность.
4. Question Activity: питомец задает вопросы, а вопросы и варианты ответов берутся из базы.
5. Pet Activities: мини-игры становятся полноценными активностями питомца и влияют на состояние, настроение или восприятие.
6. Realtime Pet Session: кандидат после аккаунтов и синхронизации; при открытой активной сессии frontend может получать обновления состояния через WebSocket/SSE.
7. Light Progression: возможные предметы, достижения и новые виды добавляются только после стабилизации основного цикла.

### DLC

Расширение после основной рабочей версии.

1. Dragon Pet: дракон становится дополнительным животным после основной версии.
2. Dragon Lifecycle: у дракона больше этапов взросления, чем у обычных питомцев.
3. Dragon Activities: мини-игры с драконом сложнее и требуют больше внимания игрока.
4. Dragon Care Risks: у дракона более требовательные условия ухода, сна, энергии и настроения.
5. AI Dragon Dialogue: с драконом можно разговаривать через AI; диалог связан с состоянием дракона и историей ухода.

Текущий backend-вектор: NestJS + PostgreSQL + Prisma. Next.js API не выбран, потому что frontend остается Angular; Supabase можно рассматривать позже как managed Postgres/Auth альтернативу.

## Старт

PostgreSQL подключается через `DATABASE_URL`; пример лежит в `.env.example`.

```bash
npm install
npm run prisma:generate
npm run dev:api
npm start
```

Pocket Pet теперь читает состояние через backend API. Для разработки запусти `npm run dev:api` и `npm start` в двух терминалах. Angular dev-server проксирует `/api` на `http://127.0.0.1:3000`.

По умолчанию Angular dev-server слушает `0.0.0.0:4200`, поэтому приложение можно открыть с другого устройства в той же Wi-Fi сети.

На компьютере открой:

```text
http://localhost:4200
```

На телефоне или другом устройстве в той же сети открой:

```text
http://<IPv4-адрес-компьютера>:4200
```

IPv4-адрес можно посмотреть командой:

```powershell
ipconfig
```

Если нужен только локальный запуск на компьютере:

```bash
npm run start:local
```
