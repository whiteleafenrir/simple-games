# Simple Games

**Pocket Pet** — браузерная игра на Angular 22 standalone components: забота о фэнтези-питомце в ограниченной жизненной сессии. Главная помогает вернуться к другу, альбом хранит общие истории. Прежние игры сохранены по прямым маршрутам и скрыты из навигации.

Стек: Angular + NestJS API + PostgreSQL 17 + Prisma 7. Состояние питомцев хранится на backend, гостевая сессия восстанавливается через HttpOnly-cookie.

«Поиграть» открывает [мини-игры с питомцем](docs/specs/pet-activities.md): «Слово в облаках» (RU/EN), крестики-нолики против питомца и шахматные задачи. Начало первой партии засчитывает заботу; следующие партии в открытом окне бесплатны. В комнате каждый день появляется [факт о животном](docs/specs/daily-animal-facts.md).

## Запуск

```powershell
npm ci
npm run dev
```

Команда использует PostgreSQL из `.env` (или поднимает стандартную Docker-базу), применяет SQL-миграции и запускает игру, API с перезапуском и Prisma Studio. На текущем компьютере уже есть PostgreSQL на порту `5435`; Docker не нужен. На новой машине нужен существующий PostgreSQL или запущенный Docker Desktop; `.env.example` содержит Docker-подключение.

При первом обновлении существующей базы после T4 выполните `npm run db:baseline` при остановленном API; для новой БД это не нужно. На текущем компьютере baseline уже зарегистрирован.

Открыть всё во втором терминале: `npm run dev:open`. Остановить приложения: **Ctrl+C**, данные сохраняются.

- [Игра](http://localhost:4200)
- [Backend: Swagger](http://localhost:3000/api/docs)
- [База: Prisma Studio](http://localhost:5555)

Диагностика: `npm run dev:doctor`. Только база и таблицы: `npm run db:studio`. Проверка сборок: `npm run check`; lint, форматирование изменений и сборки: `npm run quality`. В PowerShell при блокировке `npm.ps1` используйте `npm.cmd`.

**Подробная инструкция:** [как запускать, открывать и смотреть backend и базу](docs/backend-guide.md).

## Roadmap

Актуализировано 2026-10-04 по коду и спецификациям.

**Решения от 2026-10-10:** целевой цикл — 21 день с взрослением за первую неделю, три коротких визита в сутки и необязательная утренняя игра. Энергия игрока сохранена, скрыта и не расходуется. Длительность/возраст и баланс ещё предстоит реализовать; сон по усталости с ориентиром 5–12 часов добавлен отдельным этапом. [План и статусы](docs/plans/guest-release-cycle.md).

1. **Реализовано:** гостевой MVP и `T0–T6`; новая главная и альбом, сцена и реакции `S1–S2`, внешность и 3D-прототип кота, вопросы и доверие `Q1–Q2`, 36 вопросов RU/EN, три мини-игры (шахматы с каталогом Lichess) и ежедневные факты. Часть рабочей версии уже вошла в текущую игру.
2. **Ближайший фокус — завершение гостевой версии:** подтвердить правила первого выпуска, пройти весь цикл до прощания и нового питомца, поправить баланс (включая остаток `Q3`), затем подготовить первое общее окружение. Полная приёмка текущей версии и размещение ещё открыты; [порядок и критерии](GAME_DESIGN.md#1411-ближайший-фокус-завершение-гостевой-версии).
3. **Рабочая версия:** остаются аккаунты с переносом гостя и синхронизацией, дневной ритм, расширенное восприятие, различия видов и художественное продолжение `S3`. Для [системы уведомлений](GAME_DESIGN.md#1423-система-уведомлений) готовы раздел профиля и выдача/отзыв кода Telegram; бот и доставка ещё впереди, мобильные push — вместе с будущим приложением, Web Push не планируется. «Погладить» пока существует только как превью. Очередность этих расширений предлагается после гостевого выпуска.
4. **DLC:** дракон, расширенный жизненный цикл и AI-диалоги.

Подробный объём, техническая очередность и non-goals находятся в [roadmap GDD](GAME_DESIGN.md#14-roadmap). Причины и доказательства задач — в [аудите](docs/reports/project-audit-2026-09-07.md). Тестовое покрытие отложено до стабилизации MVP и добавляется отдельной задачей.
