# Simple Games

**Pocket Pet** — браузерная игра на Angular 22 standalone components: забота о фэнтези-питомце в ограниченной жизненной сессии. Главная помогает вернуться к другу, альбом хранит общие истории. Прежние игры сохранены по прямым маршрутам и скрыты из навигации.

Стек: Angular + NestJS API + PostgreSQL 17 + Prisma 7. Состояние питомцев хранится на backend, гостевая сессия восстанавливается через HttpOnly-cookie.

«Поиграть» открывает [мини-игры с питомцем](docs/specs/pet-activities.md): «Слово в облаках» (RU/EN) и крестики-нолики против питомца. Начало первой партии засчитывает заботу; следующие партии в открытом окне бесплатны.

## Запуск

```powershell
npm ci
npm run dev
```

Команда использует PostgreSQL из `.env` (или поднимает стандартную Docker-базу), применяет SQL-миграции и запускает игру, API с перезапуском и Prisma Studio. На текущем компьютере уже есть PostgreSQL на порту `5435`; Docker не нужен. На новой машине нужен существующий PostgreSQL или запущенный Docker Desktop; `.env.example` содержит Docker-подключение.

При первом обновлении существующей базы после T4 выполните `npm run db:baseline` при остановленном API; для новой БД это не нужно. На текущем компьютере baseline уже зарегистрирован.

Открыть всё во втором терминале: `npm run dev:open`. Остановить приложения: **Ctrl+C**, данные сохраняются.

- [Игра](http://localhost:4200)
- [Backend: Swagger](http://localhost:3000/api/docs)
- [База: Prisma Studio](http://localhost:5555)

Диагностика: `npm run dev:doctor`. Только база и таблицы: `npm run db:studio`. Проверка сборок: `npm run check`. В PowerShell при блокировке `npm.ps1` используйте `npm.cmd`.

**Подробная инструкция:** [как запускать, открывать и смотреть backend и базу](docs/backend-guide.md).

## Roadmap

1. **MVP — текущий этап:** гостевая сессия, один активный питомец, уход, сон, прогулки, энергия, взросление и сохранённый итог. Основная вертикаль и этапы `T0–T6` реализованы, включая миграции, общий API-контракт, CI и полировку UX. Локальные проверки и [первый CI сборок и миграций](https://github.com/whiteleafenrir/simple-games/actions/runs/35398936681) прошли. Далее — приёмка MVP и подготовка публикации; хостинг выбирается отдельно.
2. **Рабочая версия:** аккаунты и синхронизация, различия видов, восприятие игрока и мини-игры. [Активность «Вопросы»](GAME_DESIGN.md#1421-активность-вопросы): Q1–Q2 готовы — доверие, окно ответов и сохранённая история. В Q3 банк расширен до 36 вопросов RU/EN, по 12 на возраст. Далее — игровые прогоны и настройка баланса.
3. **Интерфейс питомца:** [S1 реализован](docs/specs/pet-scene.md) — сцена с простой анимацией, иконки действий, доступность с сервера, подсказки и мобильные карточки. Добавлены анимации шести настроений и сна, превью поглаживания и [галерея анимаций](http://localhost:4200/animations). Реализованы [временные реакции на уход, цвет/окрас и слой грязи](docs/specs/pet-appearance.md); далее — художественное оформление.
4. **DLC:** дракон, расширенный жизненный цикл и AI-диалоги.

Подробный объём, техническая очередность и non-goals находятся в [roadmap GDD](GAME_DESIGN.md#14-roadmap). Причины и доказательства задач — в [аудите](docs/reports/project-audit-2026-09-07.md). Тестовое покрытие отложено до стабилизации MVP и добавляется отдельной задачей.
